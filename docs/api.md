# 🚀 REST API Specification

The FastAPI backend exposes endpoints for managing settings, reviewing workflow histories, triggering replays, exporting documents, and checking engine status.

The base URL for all API routes is:
```
http://localhost:8000/api/v1
```

Interactive OpenAPI documentation is available locally at [http://localhost:8000/api/v1/docs](http://localhost:8000/api/v1/docs).

---

## 🏥 Health Check

### `GET /health`
Verifies backend engine status and connectivity to the local Ollama LLM runtime.

#### Response Example (`200 OK`)
```json
{
  "status": "ok",
  "service": "AgentFlow Backend API",
  "version": "1.0.0",
  "timestamp": "2026-07-27T11:20:00Z",
  "services": {
    "ollama": "online"
  }
}
```

## 🔄 Workflow Orchestrator

### `POST /workflows`
Starts a new workflow run based on the user's prompt and returns a workflow ID immediately. The orchestrator processes steps in the background.

#### Request Schema
```json
{
  "user_prompt": "Design a high-throughput microservices architecture with FastAPI and Kafka.",
  "workflow_type": "FULL_PIPELINE",
  "model": "llama3:latest",
  "max_revisions": 3,
  "max_retries": 3
}
```

#### Response Example (`202 Accepted`)
```json
{
  "workflow_id": "wf-a8c7b3d2",
  "status": "STARTED",
  "message": "Workflow pipeline initiated successfully."
}
```

## 📜 Workflow History & Replays

### `GET /history`
Returns a paginated list of historical workflow runs. Supports query filtering for titles, prompts, and statuses.

#### Request Parameters
- `search` (string, optional): Filters runs by title or prompt text.
- `status` (string, optional): Filters runs by status (`PENDING`, `RUNNING`, `COMPLETED`, `FAILED`, `CANCELLED`).
- `page` (integer, default `1`): Page number.
- `page_size` (integer, default `10`): Number of items per page.

#### Response Example (`200 OK`)
```json
{
  "items": [
    {
      "id": "run-101",
      "title": "Microservice Architecture Plan",
      "workflow_type": "FULL_PIPELINE",
      "status": "COMPLETED",
      "prompt": "Design a high-throughput microservices architecture with FastAPI and Kafka.",
      "revision_count": 1,
      "started_at": "2026-07-27T11:00:00Z",
      "completed_at": "2026-07-27T11:02:15Z",
      "final_output_preview": "# Microservice Architecture\n\n- FastAPI Gateway\n- Kafka Event Bus..."
    }
  ],
  "total_count": 1,
  "page": 1,
  "page_size": 10,
  "has_next": false
}
```

### `POST /history/{run_id}/replay`
Launches a new workflow run in the orchestrator state machine using the prompt and type of an existing run.

#### Response Example (`200 OK`)
```json
{
  "new_workflow_id": "wf-c89b7201",
  "replayed_from": "run-101",
  "status": "STARTED",
  "message": "Replay workflow wf-c89b7201 launched successfully."
}
```

### `DELETE /history/{run_id}`
Deletes a historical workflow run record.

#### Response Example (`200 OK`)
```json
{
  "message": "Run 'run-101' deleted successfully."
}
```

## 📦 Export Engine

### `POST /export`
Generates formatted reports in Markdown, JSON, or PDF format from a completed workflow run.

#### Request Schema
```json
{
  "run_id": "run-101",
  "export_format": "markdown"
}
```

#### Response Example (`200 OK` - Markdown Export)
```json
{
  "run_id": "run-101",
  "export_format": "markdown",
  "filename": "microservice-architecture-plan.md",
  "content": "# Microservice Architecture Plan\n\nGenerated by AgentFlow on 2026-07-27...",
  "download_url": "http://localhost:8000/api/v1/export/download/run-101.md"
}
```

## 🔧 Settings & Configuration

### `GET /settings`
Retrieves settings configurations for the user profile, including preferred Ollama model details and remote endpoint hosts.

#### Response Example (`200 OK`)
```json
{
  "ollama_host": "http://localhost:11434",
  "default_model": "llama3:latest",
  "enable_telemetry": true,
  "theme": "dark"
}
```

## ❌ Global Error Handling Schemas

If an endpoint fails or encounters an unhandled runtime exception, the API returns a structured error payload:

```json
{
  "error": "Internal Server Error",
  "detail": "Failed to connect to local Ollama service. Ensure 'ollama serve' is running.",
  "timestamp": "2026-07-27T11:15:30Z"
}
```
